1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya
JavaScript adalah bahasa pemrograman tingkat tinggi yang umumnya berjalan di sisi klien (client-side). Artinya, kode JavaScript dieksekusi langsung oleh web browser (seperti Chrome, Firefox, atau Edge) di komputer pengguna, tanpa harus berkomunikasi dulu dengan server.
2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
jQuery adalah sebuah library (pustaka) atau kumpulan tools JavaScript yang bersifat open-source. jQuery dibuat khusus untuk mempermudah dan mempercepat penulisan kode JavaScript.
Kegunaan utama jQuery adalah menyederhanakan tugas-tugas berat dalam JavaScript, terutama yang berhubungan dengan manipulasi elemen HTML
3. Jelaskan perbedaan JavaScript dan jQuery!
JavaScript dan jQuery memiliki perbedaan mendasar meskipun sering dianggap sama. JavaScript adalah bahasa pemrograman asli, sedangkan jQuery merupakan sebuah library (alat bantu) yang dibangun menggunakan JavaScript. Dari segi penulisan, kode JavaScript murni cenderung lebih panjang dan kompleks, sementara jQuery menawarkan sintaks yang jauh lebih singkat dan sederhana. Selain itu, JavaScript bisa berjalan mandiri, sedangkan jQuery harus dipanggil atau di-import terlebih dahulu ke dalam file HTML. Singkatnya, JavaScript adalah bahasa dasarnya, sedangkan jQuery adalah alat bantu untuk mempermudah penulisan kode JavaScript.
